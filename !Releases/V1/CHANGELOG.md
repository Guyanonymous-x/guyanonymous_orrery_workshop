# Guyanonymous' Orrery Explorer — V1 changelog

V1 is the app as it stood on 7 Nov 2026, before the "region of space" work began.
It was published as "Orrery Workshop"; the file is stored here unchanged (the title inside still says Orrery Workshop).

## What V1 does
- Build one planetary system at a time: star, planets, moons, asteroid belts, dwarf planets and comets.
- Physics checks flag anything impossible or unlikely (Roche limits, orbit spacing, star lifetimes, and so on).
- Animated top-down orbit map with log/linear scale, plus a to-scale size strip.
- Random system generator.
- Library of systems kept in the browser.
- Save/export: system JSON, whole library JSON, Celestia (.ssc/.stc), exoplanet-style CSV. Import JSON.
